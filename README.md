One Piece 项目基本功能点：

1. 登录服务

   - 注册账号
   - 登录进入系统
   - 注销已注册的账号

2. 配置服务（登录进自己的账号后可以配置此账号的环境）

   - 配置恶魔果实的克制关系
   - 支持导入默认恶魔果实克制关系

3. 角色服务

   - 提供 100 默认角色，由系统初始化时导入
   - 浏览已有角色
   - 按照角色的名字排序
   - 按照角色创建时间排序
   - 按照角色恶魔果实类型分类
   - 添加角色
     - 添加角色的时候为角色添加
       - 名字
       - 恶魔果实
       - 攻击力
       - 防御力
       - 魔力值
       - 血量
       - 智力
       - 团队增益
   - 更改角色
     - 更改自己添加角色的所有属性
   - 删除角色
   - 为角色添加恶魔果实
   - 为一组角色创建团队（海贼团）

4. 恶魔果实服务

   - 提供初始恶魔果实 70 个
   - 浏览所有恶魔果实和其当前所有者
   - 查看恶魔果实历史所有者
   - 创建恶魔果实

5. 决斗服务

   - 选择战斗人员两个
   - 计算战斗流程
   - 显示战斗结果分析

6. 团战服务
   - 选择战斗团体两个
   - 计算战斗流程
   - 显示战斗员战斗结果
   - 显示战斗结果分析
